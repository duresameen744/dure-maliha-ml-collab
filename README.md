# dure-maliha-ml-collab

Team project for Assignment 01: Git-Based Collaboration for an ML Project.

**Task:** predict whether a person earns more than 50K a year (binary classification).
**Dataset:** Adult Income, UCI Machine Learning Repository.
**Team:** Dure Sameen (Data owner, CI) and Maliha Fatima (Model owner, pre-commit, environment, releases).

The goal is that every result can be reproduced by anyone on the team:
same commit, same config, same data version, same environment, same seed.

More details will be added as the pipeline is built. See CONTRIBUTING.md for team rules.
